## 最近更新

```dataview
TABLE WITHOUT ID file.link AS "文献", default(年份, year) AS "年份", default(审核等级, review_level) AS "审核"
FROM "20_文献"
WHERE 类型 = "文献" OR type = "literature"
SORT file.mtime DESC
LIMIT 6
```

## 待完成证据审核

```dataview
TABLE WITHOUT ID file.link AS "文献", default(入库目录, library_folder) AS "目录", default(Zotero条目键, zotero_item_key) AS "Zotero"
FROM "20_文献"
WHERE (类型 = "文献" OR type = "literature") AND (证据状态 = "待审核" OR evidence_pending = true OR 审核等级 = "快速审核" OR review_level = "quick-reviewed" OR review_level = "unreviewed" OR review_level = "未复核")
SORT file.mtime DESC
LIMIT 6
```

> [!tip] 查看全部待办
> 在 [[审核队列]] 中继续进行证据审核和深度审核。
